# Windows 스모크 · 알림 확인 체크리스트 (사용자 PC)

실행 대상: `publish\win-x64\BriefingBoard.exe` (또는 리포지토리에서 원클릭 빌드)
요구: Windows 10/11 · .NET 8 Desktop Runtime(없으면 아래 `-SelfContained` 빌드) · Edge WebView2(대부분 기본 내장)

---

## 0) 산출물 준비

리포지토리의 `native/packaging`·`src`·`publish` 가 그대로 Windows로 복사되어 있다고 가정합니다.
`dist\index.html` 은 작업공간 스냅샷에서 빠지므로 **반드시 먼저 생성**:

```powershell
cd <repo>
node tools/build.js          # dist\index.html 생성 (npm install 후 1회)
powershell -ExecutionPolicy Bypass -File native/scripts/build-win.ps1 -Run
#   또는 .NET 8 설치 없이:  native/scripts/build-win.ps1 -Run -SelfContained
```

첫 실행 시:
- 보드 창이 뜨고 우상단 토글 스위치(항상 위)가 **켜진** 상태
- 우측 하단 시스템 트레이에 앱 아이콘 표시
- 닫기(X) → 창이 사라지고 **트레이는 남음**(종료 아님)

> 참고: `publish\win-x64\BriefingBoard.exe` 는 이미 최신 빌드(알림 포함)이므로,
> `node tools/build.js` 후 **그 exe를 바로 실행**해도 됩니다. 단 `publish\win-x64` 는 새 빌드가
> 덮어쓰기 전까지 dist 시점이 구버전일 수 있으니, exe 실행 전 `web\index.html` 을 확인하거나
> 위 빌드 스크립트를 사용하세요.

## 1) 알림 풍선 — 즉시 확인 (실제 뉴스/일정 없이도 가능)

트레이 아이콘 **우클릭 → 「알림 테스트 (풍선)」** 클릭.

**예상 동작**
1. 트레이 위에 풍선 1: `새 브리핑 도착 — 새 소식 2건이 들어왔어요. (테스트)` (약 5초 표시)
2. 약 2.5초 후 풍선 2: `다가오는 일정 — 15분 뒤 '주간 회의'가 시작돼요. (테스트)`
3. 풍선을 클릭하면 **보드 창이 열림**(숨겨져 있던 경우)

**통과 조건**: 두 풍선이 순서대로 뜨고, 클릭 시 보드 열림.

> Windows 알림 설정: 시작 → 설정 → 시스템 → 알림에서 "BriefingBoard"가 꺼져 있으면 풍선이
> 안 보일 수 있습니다(켜기). 실행 후 앱이 처음 알림을 보내면 Windows가 "알림 허용?"을 물을 수 있음.

## 2) 실제 "새 브리핑" 알림 (선택 · 라이브)

- 첫 실행 후 첫 수집은 **기준점(notify-state.json)**으로만 저장 → 알림 없음(의도).
- 이후 폴링(기본 15분)에서 **새 헤드라인이 생기면** 트레이 풍선 `새 브리핑 도착 — 새 소식 N건`.
- 빠르게 보려면: 트레이 우클릭 → 「뉴스 새로고침」을 몇 분 간격으로 여러 번.
  실소스가 그 사이 바뀌어야 알림이 뜨므로, 당장 확인이 목표라면 **1)번 테스트 풍선**을 사용하세요.

---

## 3) 실제 "다가오는 일정" 알림 (선택 · iCloud 필요)

1. 설정(보드 우상단 ⚙) → **네이티브 위젯 연동** → Apple ID(이메일)+**앱 특수 암호** 입력 → `연결 저장`
2. `일정 표시` 켜기 → 오늘 위젯에 실제 iCloud 일정이 보이면 성공
3. iCloud에 **지금으로부터 10분 이내 시작**하는 일정을 만들어두면
   30초 주기 감지가 시작 전 풍선 `다가오는 일정 — ○○ — 시작 전이에요.` 를 띄움(같은 일정은 1회만).

## 4) 알림 관련 회귀 항목

| 확인 | 기대 |
|---|---|
| `%LOCALAPPDATA%\BriefingBoard\notify-state.json` | 첫 수집 후 생성(seen 키 목록). 이후 재시작해도 첫 폴링에서 알림 0건 |
| `%LOCALAPPDATA%\BriefingBoard\host.json` | `notificationsEnabled:true` 기본 · `remindLeadMinutes:10` |
| 설정 UI 재오픈 | 네이티브 패널 표시(연결 상태·스위치·주기), 데모 브라우저 모드엔 안 보임 |
| 트레이 메뉴 | 보드 열기/숨기기 · 뉴스 새로고침 · **알림 테스트 (풍선)** · 항상 위 · 종료 |

## 5) 결과 보고 양식

아래 4가지를 회신해 주시면 됩니다 (스크린샷 첨부 가능):

1. `빌드/실행`: 정상 / 오류(메시지 붙여넣기)
2. **알림 테스트 풍선**: 두 풍선 순서대로 표시됨 / 안 됨 / 일부만
3. 풍선 클릭 시 보드 열림: 예 / 아니오
4. 기타 이상(트레이·항상 위·닫기 동작 등)
